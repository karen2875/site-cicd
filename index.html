Индивидуальный проект: линтинг HTML и CSS перед деплоем

Как работает пайплайн

  1. Push в ветку main запускает workflow.
  2. Задание lint проверяет все HTML- и CSS-файлы репозитория.
  3. Если ошибок нет, задание deploy публикует сайт на GitHub Pages.
  4. Если ошибка найдена, публикация пропускается и сайт остаётся прежним.

Состояние последней сборки показывает бейдж в README репозитория.
